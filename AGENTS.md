# Project workflow

The owner wants completed project changes committed and pushed to GitHub every
time. This is standing authorization to push; do not ask for confirmation again.

- Finish the requested work and run checks appropriate to the change before
  committing and pushing. Report the pushed branch and commit.
- Use the current shared branch unless the task needs an isolated branch. Fetch
  before pushing, preserve teammates' work, and resolve routine merge conflicts.
  Do not force-push or rewrite shared history.
- If everything is already pushed, verify that fact and report the existing
  commit. Do not create an empty commit.
- Roblox Studio saves and GitHub pushes are separate steps. Keep project source
  changes in Git as well as saving authorized shared Studio changes.
