# Throw Portals for Creatures

## Register

product

## Users

Roblox players collecting creatures, improving their throws and decorating a personal garden. The game supports mouse and keyboard, touch and gamepad. Players need to see the world while finding frequent actions quickly.

## Product Purpose

Charge and throw a portal, discover a creature, place it to earn money, then buy better portals and upgrades. The UI should explain the next useful action, the cost and the result without concealing the game world.

## Brand Personality

Bold, precise, magical. The user's approved direction is blocky and strong, with a violet-and-gold sanctuary lobby. Creatures should eventually follow the requested badass rarity progression.

## Anti-references

The previous oversized rainbow simulator HUD, emoji-only navigation, squishy ornament, unreadable shrinking odds and uncontrolled bouncing interfaces. The user specifically rejected soft creature art and implementations that disregard the supplied reference structure.

## Design Principles

- The world remains the focus during play.
- Purchases explain what changes before the player spends currency.
- Consistent symbols always have a written label.
- Owned, equipped, unavailable, working and failed states are explicit.
- Game economy and ownership remain server authoritative.

## Accessibility & Inclusion

Retain the existing reduced-motion, reduced-flashes and VFX-quality session settings and expose them in the UI. Use readable fixed type, visible keyboard/gamepad focus, text with color states, and touch-sized controls. Test responsive layouts in Studio; physical-device coverage must be reported separately.
