# HUD and expedition design options

Concept approval sheet; generated with the built-in imagegen tool. These UI changes
are not implemented or saved to Studio yet. Pet portraits are illustrative proposals.

1. Sanctuary: compact violet HUD and a right-side expedition drawer.
2. Skyforge: angular stone/gold widgets and a wide bottom planning panel.
3. Clearview: light stone widgets and a compact panel beside the table.

All options retain one Menu control, a money/income display, contextual mission
progress, illustrated biome selection, pet portraits, one Send pet action, and
a Claim state. Relics remain secondary. No new currencies, battle stats or paid
skips are proposed. The plan replaces dense simultaneous lists with mission
selection followed by pet selection and dispatch.
